# Project Soccer — Documentation

Canonical cross-project documentation for [Project Soccer](https://github.com/project-soccer).

## Documents

- [Game Design and Architecture](game-design-and-architecture.md): confirmed decisions, source assessment, gameplay, architecture, repository boundaries, economics, roadmap, and open questions.
- [Contribution Planning](CONTRIBUTING.md): documentation conventions and the proposed contribution workflow.

## Status

The project is in design. Canonical documentation belongs to the approved `project-soccer/game` repository under `docs/`; the founder authorized publication of the planning scaffold to GitHub on 2026-09-20. Software and documentation licensing remain undecided.

The English design document supersedes the previous Italian working document. The founder's original source files are not copied into this repository.

## Documentation policy

All documentation must be in English. Label proposals and unverified assumptions explicitly. Preserve decision identifiers when revising the design, cite evidence near the relevant claim, and distinguish test targets from measured results. Repository READMEs must not become competing versions of the canonical design.
