# ADR 0005: Validate an action laboratory before a complete match

- Status: Accepted
- Date: 2026-09-20
- Scope: Project Soccer
- Legacy references: D06, D13, D17, D18

## Context

Credible contact and network behavior are the main technical risks. A full match would hide these beneath AI and restart rules.

## Decision

First build an original rigged footballer, shared ball, movement, passing, shooting, and a two-browser room. Add a target teammate and basic switching/standing tackle to exercise control boundaries. Progress to the complete small match only after contact and correction can be assessed.

## Consequences

The laboratory is not the four-minute match: it has no goalkeepers, tactical AI, proper restarts, ranking, or economic integration. Display these limits and test actual behavior. Add animations at the start rather than postponing all animation until after networking.

## Alternatives considered

A polished full match first creates too many interacting unknowns. A capsule-only networking demo cannot establish visible foot/ball agreement.
